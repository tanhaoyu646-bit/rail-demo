# 电力机车乘务作业 3D 交互原型

## 当前完成范围

- 第一人称出勤调度室，支持 WASD 移动、Shift 加速、空格跳跃；首次点击画面后进入FPS鼠标控制，无需按住拖动。
- 通用型白色横屏出勤一体机，主体棱角已圆角化。
- 一体机流程：身份、酒测、携带物品选择、打印、纸纸核对、写卡、验卡与纸卡核对；完成后依次为小组会、人人核对、人车核对。
- 证件与规章采用实物封面，可点击选择、发光标记，并按“必选项精确集合”判定，错选干扰项不能通过。
- 快捷栏 1—6：录音笔、司机手帐、IC卡、交付揭示、证件规章、背包。
- 左上说明与底部物品栏默认折叠，通过箭头展开；常驻方向键和右侧组件提示已移除。
- 录音笔、IC卡、司机手帐、工作证使用实物扫描GLB轻量副本；右手使用上传静态手模的独立轻量副本。
- 一体机业务界面使用 CanvasTexture 直接绘制到三维屏幕材质，点击坐标通过射线映射到模型屏幕，不再使用遮挡模型的HTML界面。
- 酒测器初始竖直；酒测步骤必须点击机身左侧实体检测器，检测头随后绕空间铰链向镜头深度方向伸出。
- 房间墙体、一体机、调度桌、资料柜、长椅、座椅、圆凳和地面背包均使用独立低复杂度碰撞代理；后墙增加可开合出口门和门外地面。
- 公布揭示只读；手持纸张可举近后逐行点击正文出现下划线。纸纸、纸卡核对分别计数。
- 调度员使用铁路制服站姿 GLB 的移动端轻量副本；原始模型没有被修改。
- 人人核对从运行揭示和天气题库随机抽题。
- 司机手帐为近景自由输入，按揭示、天气、安全措施三组关键词判定。
- LKJ原型显示本轮相同的动态揭示数据和实际条数，不再另用固定51条示例。
- 证件选项每轮打乱、轮内稳定；揭示按练习编号生成，包含可报告复核的随机差异。
- 人员交互按阶段分流；非当前业务阶段只对话、给单点提示，不自动弹出手帐或跳流程。

## 暂未完成

- HXD3C完整驾驶台三维模型和真实按键位置；当前只实现LKJ画面和操作逻辑。
- 调度员及非操纵司机的骨骼动画、坐下、手势和口型。现有制服人物是合并静态网格，没有骨骼。
- 当前上传FPS手模为静态网格，没有真实手指骨骼；移动端触控、贴图预算和实机性能仍待单独验收。
- IMG、非正常行车、LKJ2000书籍，按本轮约定暂缓。
- 信号旗实物模型；本批附件中没有可明确识别的信号旗单体图。
- 教师端、正式评分表、后台数据保存和账号系统。

## 运行

```powershell
npm install
npm run dev -- --port 4174
```

打开 `http://127.0.0.1:4174/`。普通入口每次重新打开/刷新生成新练习，刷新会清空当前流程。

可复现练习：`?seed=class-demo`。`fault=none` 为无差异，`fault=published` 为公布揭示差异，`fault=card` 为首次写卡差异；未指定时随机抽取（70%一致、15%公布差异、15%卡内差异）。参数仅用于本地练习/复现，不是安全考试配置。

性能诊断入口：`?diagnostics=1`，只在本地展示GPU资源数量、帧率和浏览器提供的JS堆读数，不上传数据。
本轮实现与验证详见 [2026-09-01 验证报告](reports/session-flow-performance-20260901.md)。

## 资源说明

- 原制服人物：约 150 万三角面、约 76 MB、无骨骼和动画。
- 运行副本：`public/assets/models/railway-uniform-dispatcher-lite.glb`，约 18 万三角面、7.86 MB、纹理降至 1024×1024。
- 本批手持扫描件原件每个约 150 万三角面、70–84 MB；独立轻量副本位于 `public/assets/models/props/`，单件约 3.3–4.2 MB，原件未被修改。
- `ef43546c59063cc0b1a167b7cde63dd0.glb` 当前保留为 `duty-report-lite.glb`，未误作交付揭示；交付揭示按参考布局用同一份练习数据绘制，与公布揭示和卡内副本独立核对。
- 一体机仍是程序化近似模型。多角度检查证明不是平面假体，但照片与渲染的构图、比例不一致，因此尚未达到高保真实物复刻验收标准。
